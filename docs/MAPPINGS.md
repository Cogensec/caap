# Informative framework mappings

CAAP mapping fields are navigation aids, not claims of equivalence, coverage, endorsement, or compliance.

- OWASP Agentic mappings preserve the domain alignment in the CAAP v1.0 public-review baseline.
- NIST AI RMF mappings identify relevant lifecycle functions at a high level.
- MITRE ATLAS mappings identify a technique where the baseline supports one and otherwise use a related tactic label.

Mappings are reviewed independently from pattern identity. Correcting a mapping does not renumber a pattern. A release review SHOULD verify references against the current official framework sources and record the review date.
