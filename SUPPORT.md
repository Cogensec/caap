# Support

- Usage and integration questions: GitHub Discussions after the public repository enables them.
- Confirmed bugs: GitHub issue using the bug template.
- Pattern proposals: GitHub issue using the pattern-proposal template.
- Security or benchmark-safety issues: follow `SECURITY.md`; do not report publicly.
- Commercial assessments or assurance: use Cogensec's official contact channel.

This public project does not provide emergency incident response or authorization to test third-party systems.
