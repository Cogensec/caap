# Roadmap

## 0.1 - Public review foundation

- CAAP-200 working taxonomy and schemas
- 25 deterministic safe-sentinel reference cases
- mock, command, and HTTP adapters
- JSON, HTML, and JUnit reports
- governance, safety, and contribution controls

## 0.2 - Independent adapters

- two independently maintained agent-framework adapters
- domain-specific reference-case fixtures and richer event types
- JSON Schema validation in the default development toolchain
- report comparison and regression thresholds

## 0.3 - Profiles and composition

- coding-agent, enterprise-assistant, MCP, memory/RAG, and multi-agent profiles
- explicit attack-chain representation
- signed release manifests and reproducible evidence bundles

## 1.0 - Stable community benchmark

- working-group approval of the stable schema and scoring method
- at least 50 reviewed executable public tests
- two independent harness implementations or compatibility studies
- documented benchmark limitations and repeatability study

Dates are intentionally omitted; safety and independent validation determine readiness.
